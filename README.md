# Tesla light show - Vieze Jack - De Hut Verbouwen
A Tesla light show on the track "De Hut Verbouwen" by Vieze Jack.

The timing of this light show is sync with the original song release by Vieze Jack, which is the same as the video on his youtube channel: https://www.youtube.com/watch?v=WmzcPJ994wg

## Getting Started

### Download and play on my Tesla vehicle
If you just want to download the light show and play it on your video, you need to put the following 2 files on a USB-stick and insert it into your Tesla vehicle:
1. `Vieze Jack - De Hut Verbouwen.fseq`
2. `Vieze Jack - De Hut Verbouwen.wav`
   - Not included here, I recommend you purchase the music file from an authorized merchant)

**Note:** make sure your USB drive meets the required mentioned [here](https://github.com/teslamotors/light-show#usb-flash-drive-requirements).

### Preview/edit/improve the light show in XLights
Go to Tesla's original repository (https://github.com/teslamotors/light-show) and follow the instructions. You'll need all 3 files in this repository + the `.wav` audio file.
